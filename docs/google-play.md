## Full description

Looking for a fast QR scanner and reliable barcode reader in one lightweight utility? QR Code Scanner uses your phone’s camera to detect QR codes and barcodes without requiring an account or internet connection. Point your camera at a code for live scanning, or select an existing image from your photo library to scan a code saved in a screenshot or download.

Built for everyday scanning, QR Code Scanner processes camera frames and selected images locally on your device. Results can be copied, opened, or shared only when you choose. The app does not include advertising, account registration, cloud storage, remote decoding, product lookup, or unnecessary online services.

Live scanning includes tap-to-focus, pinch-to-zoom, and torch control for codes that are small, distant, or in darker environments. Repeated detection filtering helps reduce unstable or accidental results while still responding quickly when a readable code is found.

QR Code Scanner also includes private local history for up to 50 unique results. Repeat scans move back to the top instead of creating duplicates. Each saved result includes the scanned value and timestamp, and all history can be cleared at any time.

QR Code and Barcode Scanning

* Live Camera Scanner: Point your camera at a supported QR code or barcode to detect and display its contents.
* Scan from Image: Select one image through Android’s Photo Picker and scan it locally without broad photo-library access.
* Tap to Focus: Tap the camera preview to focus on a specific code.
* Pinch to Zoom: Zoom in when scanning small, distant, or tightly printed codes.
* Torch Control: Add light when scanning in darker environments.
* Stable Detection: Filtering helps prevent duplicate or unstable results.

Supported Code Formats

* QR Code
* EAN-13 and EAN-8
* UPC-A and UPC-E
* Code 39, Code 93, and Code 128
* Codabar
* ITF
* PDF417
* Aztec
* Data Matrix

Scan Result Actions

* Copy: Place a scanned result on the Android clipboard.
* Open: Open supported HTTP or HTTPS web addresses in a compatible app.
* Share: Send a result through Android’s standard share sheet.
* Clear Result: Hide the current result without deleting saved history.

For safer link handling, QR Code Scanner validates scanned web addresses before enabling Open. Unsupported schemes, malformed addresses, embedded user information, control characters, backslashes, and non-standard ports are blocked.

Local Scan History

* Saves up to 50 unique accepted results
* Stores the scanned value and timestamp
* Moves repeat scans back to the top
* Keeps history in private local app storage
* Allows all saved history to be cleared at any time
* Disables Android cloud backup for app data

Privacy-Focused Design

QR Code Scanner performs QR code and barcode recognition on your device using the bundled ML Kit model. Camera frames and selected images are not uploaded by the app, and selected images are not copied into app storage.

The app has no user accounts, advertising, analytics, tracking, cloud history, subscriptions, or login requirements. Core scanning works without an internet connection. External apps or websites receive a result only when you choose Copy, Open, or Share.

Key Features

* Fast QR code and barcode scanning using the rear camera
* Local scanning from one selected image
* Support for common barcode formats
* Tap-to-focus and pinch-to-zoom camera controls
* Built-in torch control for darker environments
* Private history for up to 50 unique results
* Copy, Open, Share, and Clear actions
* Safer validation before opening web links
* No ads, login, or account registration
* No internet connection required for scanning
* Lightweight interface without unnecessary clutter
* Open-source code available for inspection on GitHub

QR Code Scanner is a focused, private, and dependable QR code and barcode utility without unnecessary clutter or online services.
